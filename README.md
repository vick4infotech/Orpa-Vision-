# ORPA Vision Website

One-page static website for ORPA Vision Travels & Consult.

## Deploy on Vercel

1. Upload this folder or connect it to a Git repository.
2. Keep the framework preset as **Other**.
3. Build command can be left empty or set to `npm run build`.
4. Output directory should be the project root.
5. Deploy.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive layout and brand styling
- `script.js` - interactions for tabs, travel request, checklist, steps, and FAQs
- `assets/` - ORPA Vision graphics and favicon
- `vercel.json` - static routing configuration for Vercel
