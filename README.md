# ORPA Vision Website

One-page static website for ORPA Vision Travels & Consult.

## Deploy on Vercel

1. Upload this folder or connect it to a Git repository.
2. Keep the framework preset as **Other**.
3. Set the build command to `npm run build`.
4. Set the output directory to `public`.
5. Deploy.

## Files

- `public/index.html` - page structure and content
- `public/styles.css` - responsive layout and brand styling
- `public/script.js` - interactions for tabs, travel request, checklist, steps, and FAQs
- `public/assets/` - ORPA Vision graphics and favicon
- `vercel.json` - static routing configuration for Vercel
